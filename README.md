# ChemAI: Predict the Cure



Проект выполнен в рамках хакатона **ChemAI: Predict the Cure**.



Задача соревнования — построить ML-пайплайн для предсказания биологической активности химических соединений против вируса гриппа.



## Задача



Для каждого химического соединения необходимо предсказать три целевые переменные:



- **IC50** — концентрация вещества, при которой подавляется 50% биологической активности вируса;

- **CC50** — концентрация, при которой наблюдается токсичность для 50% клеток;

- **SI** — Selectivity Index, индекс селективности соединения.



Метрика соревнования — средний RMSE по трём таргетам:



```text

score = (RMSE(IC50) + RMSE(CC50) + RMSE(SI)) / 3

```

## Данные


В соревновании используются данные о химических соединениях, описанных числовыми молекулярными дескрипторами.



Обучающая выборка содержит:



- молекулярные признаки;

- целевые переменные `IC50, mM`, `CC50, mM`, `SI`.



Тестовая выборка содержит только молекулярные признаки. Для неё необходимо сформировать файл предсказаний в формате `sample_submission.csv`.



Основные группы признаков:



- молекулярные свойства: `MolWt`, `ExactMolWt`, `HeavyAtomMolWt`, `MolLogP`, `MolMR`, `TPSA`;

- электронные и зарядовые характеристики;

- топологические дескрипторы;

- VSA-дескрипторы;

- функциональные группы `fr\_\*`;

- BCUT2D и EState-дескрипторы.



## Краткое описание решения



В ходе работы был построен пайплайн решения для табличной регрессии.



Основные этапы:



1. Загрузка данных.

2. Первичный анализ структуры датасета.

3. Проверка пропусков и типов данных.

4. Анализ распределений целевых переменных.

5. Проверка связи между `IC50`, `CC50` и `SI`.

6. Поиск и обработка дубликатов.

7. Удаление конфликтных дубликатов.

8. Обучение модели `ExtraTreesRegressor`.

9. Проверка альтернативных моделей.

10. Формирование submission-файла для Kaggle.



## Анализ данных



В данных были обнаружены:



- сильная асимметрия распределений целевых переменных;

- выраженные хвосты у `IC50`, `CC50` и особенно у `SI`;

- небольшое количество пропусков в некоторых молекулярных дескрипторах;

- дубликаты по признакам;

- конфликтные дубликаты: строки с одинаковыми молекулярными признаками, но нестабильными значениями целевых переменных.



Особенно важным оказалось обнаружение конфликтных дублей. Такие строки могут ухудшать обучение модели, потому что одинаковым признакам соответствуют разные значения таргетов.



После анализа были удалены плохие дубликаты, то есть наблюдения с одинаковыми признаками и нестабильным значением `SI`.



## Модель



Финальная модель:



```text

ExtraTreesRegressor

```



Модель была выбрана потому, что:



- хорошо работает на небольших табличных данных;

- устойчива к выбросам и нелинейным зависимостям;

- не требует масштабирования признаков;

\- показала лучший результат на Kaggle среди протестированных подходов.


Для обработки пропусков использовался `SimpleImputer` со стратегией `median`.



Итоговый пайплайн:



```text

SimpleImputer(strategy="median") → ExtraTreesRegressor

```



## Проверенные альтернативы



В ходе экспериментов были также протестированы:



- `XGBoostRegressor`;

- `CatBoostRegressor`;

- линейные модели с `log1p`-преобразованием таргетов;

- отдельные модели для каждого таргета;

- удаление хвостовых значений `SI`;

- использование предсказанного `IC50` как дополнительного признака для `CC50`;

- отбор признаков по важности;

- разные варианты очистки train.



Некоторые подходы давали небольшое улучшение на локальной кросс-валидации, однако на Kaggle Public Leaderboard ухудшали результат. Поэтому в качестве финального решения была выбрана наиболее стабильная схема: `ExtraTreesRegressor` на очищенном train.

## Формат submission



Файл для отправки на Kaggle должен содержать 4 колонки:



```text

index, IC50, CC50, SI

```



Пример:



```text

index,IC50,CC50,SI

0,0.723678,0.426328,0.308486

1,0.804617,0.643166,0.179750

```
